# Callback interface plan

Visual thesis: a quiet dark-slate identity control room, with a violet twin and
clear amber pending, red blocked, and green verified states from the brief.

Content plan: landing introduces Callback with one large Gate diagram and two
actions; the call workspace prioritizes transcript and input; the console
prioritizes actual effects, signatures and production status, with logs below.
Use aligned columns and dividers. Cards are reserved for actionable changes.
The first release is text mode and explicitly shows production apply disabled.

Interaction thesis: reveal a call's twin into the workspace; animate a change
card toward the Gate when confirmation is requested; expand logs and before/after
evidence in place. Respect reduced motion. The phone page later makes exact
effects and Approve/Deny the primary controls.

Two type styles: system sans for operations, system monospace for identifiers and
diffs. No decorative imagery, unrelated charts, or invented performance numbers.
The Gate is the main visual and the operational state display.
